# ステップ１

グリッドの左上から下か右に移動を繰り返して右下に行く方法は何通りあるかを求める

DPの典型的な問題でdp[i][j] = (i, jにたどりつくルートの総数)とすると

dp[i][j] = dp[i-1][j] + dp[i][j-1]

として左上から順番に埋めていくことで求められる。

また数学的に考えると右下にたどりつくまでには「右にn-1回、下にm-1回移動する組合せ」を求めることに等しく、
これはC(m + n - 2, n - 1)と求められる。
これはPythonのmath.combを使うことで直接求めることも可能だがこれで返ってくる値はfloatだった記憶なので
使うなら精度のことを気にしないといけないかも。
と思ったが、気のせいでおそらく多倍長整数でちゃんと計算されている。

